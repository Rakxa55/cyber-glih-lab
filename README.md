# 🧪 Cyber Glih Lab

Repository ini berisi dokumentasi aktivitas *Cybersecurity*, analisis penganalisaan jaringan, pengetesan celah aplikasi web, serta *writeup* penyelesaian tantangan CTF / TryHackMe.

---

### 📁 Struktur Laboratorium
- `network-scanning/` : Hasil pemindaian port & jaringan (Nmap, Wireshark).
- `web-security/` : Catatan pengujian celah keamanan web (Burp Suite).
- `scripts/` : Script otomatisasi (Bash / Python).
- `writeups/` : Catatan penyelesaian tantangan hacking (TryHackMe / OverTheWire).

---

### 🛠️ Lab Environment
- **OS:** Linux Mint (macOS Custom Desktop)
- **Tools:** Nmap, Wireshark, Burp Suite, Docker, VS Code
- **Platforms:** TryHackMe, OverTheWire Bandit
